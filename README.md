# EduFullstack

EduFullstack is a full-stack educational management platform for universities and colleges. It provides role-based access for Admins, Lecturers, and Students to manage exams, grading, courses, and results.

## Features

- Role-based dashboards for Admin, Lecturer, and Student
- Exam creation, scheduling, and grading
- Student exam participation and result viewing
- Course and program management
- Secure user authentication and access control
