# EduFullstack Documentation

EduFullstack is an educational management system supporting three main roles:

- **Admin:** Manages lecturers, students, programs, courses, and user access.
- **Lecturer:** Creates exams, manages classes, grades submissions.
- **Student:** Takes exams, views classes, checks results.
