# Usage

## Roles & Access

### Admin

- Manage lecturers, students, programs, courses, and users.
- Assign roles and access control.
-eg.dwamo EduClass2026!

### Lecturer

- Create and manage exams for assigned courses.
- Grade student submissions and provide feedback.
-eg. sunu TestPass2026!

### Student

- View available exams and enrolled courses.
- Take exams and view results.
-eg. sun TestPass2026!

## User Flow

1. **Login** with your credentials.
2. **Navigate** using the dashboard menus based on your role.
3. **Perform actions** (e.g., create exams, grade, view results) as permitted by your role.
